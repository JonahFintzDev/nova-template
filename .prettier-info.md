# Prettier Configuration

This project uses Prettier for code formatting with the following configuration:

## Configuration

Both `app/dashboard` and `app/api` have `.prettierrc.json` files with:

```json
{
  "semi": true,
  "singleQuote": true,
  "trailingComma": "all",
  "printWidth": 100
}
```

## Usage

### Install dependencies first

```bash
# In app/dashboard
cd app/dashboard
npm install

# In app/api
cd app/api
npm install
```

### Format all files

```bash
# Dashboard
cd app/dashboard
npm run format

# API
cd app/api
npm run format
```

### Check formatting without writing

```bash
# Dashboard
cd app/dashboard
npm run format:check

# API
cd app/api
npm run format:check
```

### Format specific files

```bash
# Using npx prettier directly
npx prettier --write src/main.ts
npx prettier --write "src/**/*.{ts,vue}"
```

## Formatting Rules

- **Single quotes** for strings
- **Semicolons** at end of statements
- **Trailing commas** in objects and arrays
- **100 character** line width

## Editor Integration

### VS Code

Install the Prettier extension and add to your `settings.json`:

```json
{
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "editor.formatOnSave": true,
  "[typescript]": {
    "editor.defaultFormatter": "esbenp.prettier-vscode"
  },
  "[vue]": {
    "editor.defaultFormatter": "esbenp.prettier-vscode"
  }
}
```

### JetBrains (WebStorm, IntelliJ)

1. Install Prettier plugin
2. Go to Settings > Languages & Frameworks > JavaScript > Prettier
3. Enable "Run on save"
4. Set Prettier package to `node_modules/prettier`

## Note

Some files were manually formatted during setup. For complete formatting:

```bash
# After installing dependencies in both directories
cd app/dashboard && npm run format
cd ../app/api && npm run format
```

This will format all TypeScript, Vue, JSON, CSS, and Prisma files.
